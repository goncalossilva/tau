# Publishing preparation

Use this checklist when the task includes preparing a model for a platform such as Printables. Do not upload or publish merely because a model, preview, or STL was requested.

Typical assets:

1. STL file(s) from [export-stl.sh](../scripts/export-stl.sh), covering the intended parts and variants.
2. Preview images, including a strong hero/isometric view and useful additional angles. Follow [visual validation](../SKILL.md#visual-validation) for geometry changes.
3. A description covering customizable parameters, print settings, and assembly/use notes.
4. License, category, and tags appropriate to the model and platform.

Distinguish recommended print settings from settings actually tested. Supply the requested assets and copy; treat uploading or publishing as a separate action requiring user authorization.
